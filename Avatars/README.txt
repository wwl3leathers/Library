AVATARS

PURPOSE
Canonical identity, personality, behavioral, and visual-reference sources for named avatars.

STRUCTURE
Rin/: Complete current Rin source set and start-here instructions.
Vale/: Reserved for Vale's future source set. It intentionally contains no avatar sources yet.

USAGE
Open the chosen avatar's README.txt and follow its stated reading order.
Do not merge one avatar's identity, behavior, backstory, mannerisms, or visual traits into another avatar.
Do not alter these sources merely to fit a current conversation. Changes require Butch's explicit permission.
